01 / Why this project?
?

จากวิชาในห้อง → ชิ้นงานที่จับต้องได้

โปรเจกต์นี้จัดทำขึ้นเพื่อศึกษาหลักการเขียนโปรแกรมและการควบคุมอุปกรณ์ Tang Nano 20K โดยนำความรู้จากวิชาที่เรียนมาประยุกต์สร้างชิ้นงานจริง เพื่อเพิ่มทักษะและความเข้าใจในการเรียนรู้ให้มากขึ้น

อธิบายแบบง่าย: ลองคิดว่า FPGA เป็น “กล่อง LEGO ดิจิทัล” — เราไม่ได้แค่สั่งโปรแกรมให้ทำงาน แต่กำหนดให้วงจรข้างในทำหน้าที่นับเวลา วาดตัวเลข และส่งภาพออก HDMI ด้วย

04 / Data Pipeline

เวลา 1 วินาทีเดินทางไปถึงหน้าจอได้อย่างไร?

ดูเป็น 5 สเต็ป — เหมือนส่งต่อข้อมูลในสายพานโรงงานดิจิทัล

Step 01
🧠

Clock source

บอร์ดใช้สัญญาณนาฬิกา 27 MHz เป็นจังหวะอ้างอิง

Step 02
⏱️

นับเวลา

แบ่งจังหวะลงมาเป็น 1 วินาที แล้วนับ วินาที → นาที → ชั่วโมง

Step 03
🎛️

ปุ่ม S1 / S2

S1 เพิ่มชั่วโมง ส่วน S2 เพิ่มนาทีและรีเซ็ตวินาทีเป็น 00

Step 04
🧩

วาดตัวเลข

ค่าตัวเลขถูกส่งไปยังระบบวาดหน้าจอให้เป็นภาพนาฬิกา

Step 05
🖥️

HDMI Output

ภาพถูกส่งออกผ่าน HDMI ไปยังจอในความละเอียด 1280×720

💡 ทำไมปิดไฟแล้วเวลาไม่จำ?

FPGA ตัวนี้ไม่มีนาฬิกาแบบมีแบตเตอรี่สำรองในตัว เมื่อปิดไฟแล้วเปิดใหม่ ระบบจึงกลับไปเวลาเริ่มต้นที่ตั้งไว้ ถ้าอยากให้จำเวลาได้จริงต้องเพิ่มโมดูล RTC เช่น DS3231

🕒 24-hour clock

ระบบทำงานแบบนาฬิกา 24 ชั่วโมง เมื่อถึง 23:59:59 จะวนกลับเป็น 00:00:00 

// idea แบบย่อจาก digital_clock.v
if (S1_pressed)  hour = hour + 1;
if (S2_pressed) {
    minute = minute + 1;
    second = 0;
}
if (time == 23:59:59)
    time = 00:00:00;
05 / Manual Overrides

ปุ่มสองปุ่ม = ตั้งเวลาได้ทันที

S1 เพิ่มเวลา 1 ชั่วโมง เช่น 10:25:30 → 11:25:30

S2 เพิ่มเวลา 1 นาที และรีเซ็ตวินาทีเป็น 00 เพื่อช่วยตั้งเวลาให้ตรงขอบนาทีได้ง่าย

↑ กลับไปลองกดปุ่มจริง
06 / Debug Quest

เจอ Error? เปิดดู Patch ได้เลย

ให้น้อง ๆ เห็นว่าโปรเจกต์จริงอาจพบปัญหาระหว่างการทำงาน และเรียนรู้วิธีแก้ไขไปทีละขั้น

ตัวเลขไม่แสดงบนหน้าจอ
ตรวจสอบโค้ด Display, การเชื่อมต่อ HDMI และตั้งค่าความละเอียดของจอให้ถูกต้อง
นำโค้ดลง Tang Nano 20K โดยตรงไม่ได้
Compile โค้ด Verilog เป็นไฟล์สำหรับ FPGA ก่อน แล้วจึงดาวน์โหลดลงบอร์ด
คอมพิวเตอร์ไม่พบสาย USB หรือบอร์ด
ตรวจสอบว่าสาย USB รองรับ Data ทดลองเปลี่ยนสาย/พอร์ต และเช็ก Driver
ต้องติดตั้งโปรแกรมเพิ่ม
ติดตั้ง Gowin EDA และ Driver ที่จำเป็นสำหรับ Compile และดาวน์โหลดโปรแกรมลงบอร์ด
