DIGITAL CLOCK SHOWCASE WEBSITE
==============================

ไฟล์หลัก:
- index.html = หน้าเว็บไซต์ทั้งหมด
- assets/ = รูปประกอบจากสไลด์โครงงาน
- Source Code: https://drive.google.com/drive/folders/15pTe8nUgxk8EE6tcMdV6ZXwY4LSYgSCo?usp=sharing

วิธีเปิดแบบง่ายที่สุด
1) แตกไฟล์ ZIP นี้
2) เปิด index.html ด้วย Chrome / Edge / Safari / Firefox
3) ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

ถ้าจะนำขึ้นออนไลน์
- อัปโหลดทั้งโฟลเดอร์ digital_clock_showcase ไปยังบริการ Static Web Hosting
  เช่น GitHub Pages / Netlify / Cloudflare Pages
- ไม่ต้องมีฐานข้อมูล และไม่ต้องติดตั้ง framework

จุดที่แก้ข้อความได้ง่าย
- เปิด index.html ด้วย Notepad / VS Code
- ค้นหาคำว่า Team Six Seven, ชื่อสมาชิก, หรือหัวข้อที่ต้องการแก้
- รูปทั้งหมดอยู่ในโฟลเดอร์ assets

สิ่งที่ออกแบบเพิ่มให้
- Responsive Design
- Retro Windows UI ตามธีมงานเดิม
- Boot Animation
- Interactive Digital Clock
- ปุ่ม S1/S2 จำลองการตั้งเวลา
- Step-by-step System Pipeline
- Debug Accordion
- Gallery ผลงานจริง
- Source Code Download

หมายเหตุด้านความเป็นส่วนตัว
เวอร์ชันนี้ไม่แสดงรหัสนักศึกษาเต็มบนหน้าเว็บสาธารณะ
